Aide — Format des listes & bonnes pratiques

        
      


      

        

          Objectif : tu peux ajouter/modifier des listes sans changer le code.
          L’app lit des fichiers JSON (catalogue + listes). En mode GitHub Pages, l’app ne peut pas écrire dans le repo :
          pour personnaliser, utilise Importer / Exporter.
        


        

          1) Catalogue des listes (data/index.json)
          
Ce fichier déclare les listes visibles dans le catalogue (cartes).

          
{
  "version": 1,
  "lists": [
    {
      "id": "string_unique",
      "label": "string_humain",
      "description": "string_optionnelle",
      "tags": ["tag1", "tag2"],
      "path": "data/lists/mon_fichier.json"
    }
  ]
}

          

            Règles : id unique et stable (snake_case), path = chemin exact dans le repo.
          

        


        

          2) Fichier d’une liste (data/lists/<id>.json)
          
Chaque liste contient des items tirables. On utilise des objets pour rester extensible (tags, poids, meta).

          
{
  "id": "ma_liste",
  "label": "Ma liste",
  "version": 1,
  "items": [
    {
      "id": "item_1",
      "label": "Item 1",
      "tags": ["optionnel"],
      "weight": 1,
      "meta": {}
    }
  ]
}

          

            Recommandé : items[].id doit être unique dans la liste (slug). weight par défaut = 1.
          

        


        

          3) Sortie JSON générée
          
Le résultat est un JSON exploitable et copiable :

          
{
  "recipe_id": "kirby_worlds+software_testing_themes",
  "selected_lists": [
    { "id": "kirby_worlds", "label": "Univers & mondes – Kirby" }
  ],
  "result": {
    "kirby_worlds": { "id": "dream_land", "label": "Dream Land" }
  },
  "combination_id": "hash",
  "generated_at": "2026-02-04T12:34:56.000Z"
}

        


        

          Note performance : si tu ajoutes beaucoup de listes ou d’items, l’UI restera fluide grâce à la recherche
          et au rendu en cartes. Si un jour tu dépasses plusieurs milliers d’items visibles, on activera une optimisation (virtualisation).
        

      


      

        
      

    

  

  
  
    

      

        
Gérer mes listes

        
      


      

        

          Ici, tu peux importer tes propres listes (JSON) et elles seront stockées dans ton navigateur.
          Tu peux aussi exporter ton catalogue local. Aucun serveur, aucun compte.
        


        

          
Importer

          
Importe un fichier JSON au format “Catalogue” ou “Liste”. L’app détectera le type.
